# SAP BTP Developer in CAPM (Cloud Application Programming Model)
*A 12-week program for freshers to build enterprise-grade full-stack applications on SAP Business Technology Platform.*

---

## PROGRAM OVERVIEW

### What this program is about
Build enterprise full-stack cloud applications using the **SAP Cloud Application Programming Model (CAPM)**, **Node.js/TypeScript**, **SAP CDS**, **Core Data Services**, **SAP Fiori / SAPUI5**, and **SAP HANA Cloud**. Learn how to develop, extend, secure, and deploy modern enterprise applications on **SAP BTP (Cloud Foundry & Kyma runtime)**.

### One project, start to finish
You will work in a single workspace throughout the program. 
- **Project 1 (Guided):** Core CAP service with CDS modeling and HANA database binding.
- **Project 2 (Pair Project):** Full-stack SAP Fiori Elements application with OAuth2 authentication and destination service integrations.
- **Project 3 (Capstone):** End-to-end custom business scenario (e.g., Enterprise Order & Inventory Management System) built from scratch, secured, and deployed to SAP BTP live environment.

### How your time is spent
- **20%** Concepts & Architecture
- **65%** Hands-on Development & SAP Tools
- **15%** Reviews, Mock Interviews & Capstone Projects

### A typical 6-hour day
- **1.5h** Concept / Instructor Session (SAP BTP & CAP Architecture)
- **2.0h** Hands-on Coding (CDS, Node.js logic, SAPUI5/Fiori)
- **1.5h** Project Development & Integration Exercises
- **0.5h** AI-assisted Development (SAP Business Application Studio, SAP Joule / AI assistance)
- **0.5h** Code Review / Assignment / Discussion

## CURRICULUM

### 10 Steps from Enterprise Basics to Live BTP Deployment

| Step | Duration | Module Title | Topics Covered | Deliverable |
| :--- | :--- | :--- | :--- | :--- |
| **01** | Weeks 1–2 | **Enterprise Web & JavaScript/TypeScript Foundations** | Modern JavaScript (ES6+), Async/Await, Node.js fundamentals, TypeScript basics, REST API principles, OData protocol concepts, Git/GitHub workflows. | Interactive JavaScript Node.js CLI App |
| **02** | Week 3 | **Introduction to SAP BTP & CAP Setup** | SAP BTP overview (Cloud Foundry environment, Subaccounts, Entitlements), SAP Business Application Studio (BAS), `@sap/cds-dk` CLI setup, CAP project structure. | Initialized CAP project with BAS workflow |
| **03** | Week 4 | **Data Modeling with Core Data Services (CDS)** | CDS syntax, entity definitions, associations (`to-one`, `to-many`), compositions, common types, localized data, aspect usage (`cuid`, `managed`). | Domain Model Definition (`db/schema.cds`) |
| **04** | Week 5 | **Developing CAP Services & Business Logic** | Defining OData V4 services (`srv/cat-service.cds`), custom event handlers (`BEFORE`, `ON`, `AFTER`), entity validation, messaging, custom functions & actions. | Expressive CAP Backend with Custom Logic |
| **05** | Week 6 | **Databases & SAP HANA Cloud Integration** | SQLite local testing, SAP HANA Cloud configuration, HDI Containers, CDS deployment (`cds deploy`), schema migrations, native HANA artifacts. | CAP Service connected to SAP HANA Cloud |
| **06** | Weeks 7–8 | **UI Development with SAP Fiori & SAPUI5** | SAP Fiori annotations (`@UI.LineItem`, `@UI.HeaderInfo`), Fiori Elements (List Report, Object Page), SAPUI5 custom controls, OData model binding. | Complete SAP Fiori UI App for CAP Backend |
| **07** | Week 9 | **Authentication, Security & SAP XSUAA** | SAP Authorization and Trust Management (XSUAA), Application Router (AppRouter), `@sap/xssec`, role collections, scopes, attribute-based access control (ABAC). | Secure Role-Based Access Control Setup |
| **08** | Week 10 | **BTP Service Integrations** | SAP BTP Destination Service, Connectivity Service, consuming external REST/OData APIs, SAP Event Mesh (Asynchronous messaging), Cloud Logging. | Multi-service Integrated Enterprise App |
| **09** | Week 11 | **Automated Testing & Enterprise Quality** | CAP test framework (`@sap/cds/test`), Jest unit testing, OData service testing with Postman, SAP Fiori end-to-end testing (wdi5/OPA5). | Automated Test Suite for CAP Services |
| **10** | Week 12 | **CI/CD, Deployment & Capstone Demo** | Cloud MTA (Multi-Target Application) build, `mta.yaml` modeling, Cloud Foundry deployment (`cf deploy`), SAP BTP CI/CD Service, Final capstone presentation. | Live Deployed SAP BTP CAP Application |
